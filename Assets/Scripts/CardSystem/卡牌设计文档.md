# 卡牌设计文档

## 动态卡面规则

- 卡面不显示 `Base attack`，统一显示为当前实际数值。
- `攻击力+X` 在卡面上显示为当前攻击力计算后的最终伤害。
- 若玩家被[烧伤]导致攻击力降低，相关卡牌和平A显示会同步变化。
- 若藏品提供元素伤害加成，卡面显示应包含该加成。
- 费用显示使用实际费用：藏品减费、临时减费和卡牌自身减费都要反映在卡面上。
- 除非牌面特别注明最低费用，费用减免可以将卡牌费用降至0。
- 无属性牌默认使用后移出本场战斗；只有返回手牌、进入弃牌堆或洗入抽牌堆时才写在牌面上。

## 收益预算

| 费用 | 目标收益 | 说明 |
| ---- | -------- | ---- |
| 0 | 8-18 | 主要用于节奏、弃牌、结束回合、延迟收益 |
| 1 | 20-35 | 约等于20伤害、20护盾、一次小治疗或摸牌 |
| 2 | 35-50 | 伤害+状态、护盾+功能、抽牌+条件收益 |
| 3 | 50-70 | 强单体、持续收益、关键状态或构筑奖励 |
| 4 | 70-95 | 高伤害、强吸血、群体效果或多段收益 |
| 5 | 90以上 | 终结牌、群体强牌，或需要构筑降费 |

基础换算：1伤害=1收益，1护盾≈0.8收益，1治疗≈0.7收益，摸1张牌≈12-15收益，获得1能量≈12收益，常规负面状态≈10-18收益，硬控状态≈25收益以上。

## 基础动作

| 动作 | 费用 | 效果描述 |
| ---- | ---- | -------- |
| 普通攻击 | 1 | 造成当前攻击力的物理伤害并结束回合 |

普通攻击是保底动作，不占用卡组和抽牌。它低于同费用卡牌收益，用于卡手或缺少攻击牌时兜底。

## 状态与关键词

[烧伤]：在接下来2回合开始时受到10点火焰伤害，攻击力降低50%
[腐蚀]：在接下来2回合开始时受到10点暗影伤害，受伤时额外扣除5生命
[冰霜]：在接下来2回合开始时受到5点冰霜伤害
[冰冻]：在接下来2回合开始时受到5点冰霜伤害，本回合无法行动
[中毒]：每回合开始时损失当前生命值的10%（至多30点）
[眩晕]：本回合无法行动
[流血]：在接下来2回合开始时受到10点暗影伤害，并且无法回复生命值
[混乱]：下次攻击时，会攻击自己
[虚弱]：下次攻击时，攻击力-10
[沉默]：本回合起，无法使用卡牌，持续两个回合
[净化]：本回合起无法触发额外效果，持续三个回合
[复苏]：每个回合结束时，回复生命值上限20%的生命
[寄生]：每个回合结束时，失去10%最大生命，令来源回复造成伤害的50%生命
[星祈]：回合开始时获得12护盾；若上一回合未损失生命，则回复8生命。失去护盾不算损失生命。
[冷泉]：本回合下一次触发[蒸发效果]时，额外造成10点冰霜伤害。

[无属性牌说明]除非牌面注明进入弃牌堆、返回手牌或洗入抽牌堆，否则使用后移出本场战斗。
[燃烧伤害]：当你造成[火焰伤害]时，若敌方拥有[寄生]或上次受到的是[生机伤害]，则伤害量增加当前攻击力。
[蒸发效果]：当你造成[冰霜伤害]时，若敌方上次受到的是[火焰伤害]，随机清除对面一个增益效果。
[丰饶生长]：当你造成[生机伤害]时，若敌方上次受到的是[冰霜伤害]，延长对面随机一个负面效果一个回合。
[光暗双生]：当你造成[暗影伤害]/[圣光伤害]时，若敌方上次受到的是[圣光伤害]/[暗影伤害]，使自身下一次受到伤害-10（不可叠加）。
