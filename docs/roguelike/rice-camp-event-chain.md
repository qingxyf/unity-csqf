# 野生营地与大白饭讨债事件

每局每个事件仅能遇到一次。初始事件池有 19 个可遇事件；吃光米饭后，第 20 个事件「大白饭的讨债人」加入本局随机池。重排、扩充事件列表或创建新的 EventManager 不会使已遇事件再次出现。事件耗尽时显示「静谧的路口」，可以继续前行，不发放额外奖励。新开一局会重置已遇事件与解锁状态。

| 事件与选项 | 效果与走向 |
| --- | --- |
| 野生营地 → 吃一点大米饭 | 恢复 15 生命，不解锁讨债事件 |
| 野生营地 → 吃光大米饭 | 恢复 30 生命、最大生命 +8；按 PlayerStats 的既有上限提升规则，当前生命同步 +8。按钮和结果均提示事件进入新的走向 |
| 大白饭的讨债人 → 上交所有的钱 | 交出选择当时的全部金币，允许零金币；结果显示实际交出数量 |
| 大白饭的讨债人 → 进入一场艰难的战斗 | 与蓝色大肥鱼单独战斗：240 生命、24 攻击、20 初始护盾 |

两张事件插画分别呈现残破营地中的热米饭电饭锅，以及蓝发鲸鱼女仆面对空锅来讨债。蓝色大肥鱼以提供的人物图为原型，使用原创待机与料理铲攻击姿态。贴图在 `Assets/Art/Roguelike/Events` 与 `Assets/Art/Roguelike/Enemies/RiceKeeper`；提示词在 [rice-camp-art-prompts.md](rice-camp-art-prompts.md)。

后续事件只进入随机池，不保证紧接着出现；在吃光米饭以前不会遇到。战斗沿用当前 Event 节点与会话，隐藏旧事件界面并阻止旧继续回调跳过战斗。胜利获得 35 金币、最多选择两张卡牌，并随机获得一件米饭专属藏品：特殊的金属盆（每次受到伤害时有 30% 概率减免 5 点，不低于零）或大米饭（每场战斗的前三回合各恢复 10 生命和 1 能量）。另一件必定出现在下一家商店的藏品位，同店刷新保留，买过不再出现，未买离店不顺延。两件专属藏品不进入普通掉落、精英或随机商店池。领完奖励后完成原事件节点，败北结束本局且不发放专属奖励。它不是最终领袖，不会触发通关。

EventData 用稳定 `eventId` 区分新事件；已有事件以名称作为稳定身份。EventChoice 使用 `unlockEventId`、`surrenderAllGold` 和 EventCombatEncounter 描述分支。战斗启用条件是非空资源路径，因为 Unity 的内联自定义类序列化可能将空引用恢复为空对象，见 [Unity 序列化规则](https://docs.unity3d.com/2022.3/Documentation/Manual/script-Serialization.html)。默认事件编辑器创建器更新已有对象而保留 GUID。

EditMode 覆盖一次性抽取、身份/来源变化、后续事件解锁、藏品回合效果、掉落概率边界与重开。PlayMode 覆盖实际按钮、收益、金币归零/零金币、插图布局、战斗原节点绑定、旧回调拦截、胜利专属奖励、次店必出与刷新/购买、败北与重开清理。本机可用 Unity Editor 执行测试，GitHub Actions 继续验证测试和构建。
