# 原创战斗小人

`forth` 的战斗敌人使用本项目生成的原创 SD 角色。PRTS 的敌人模型仅用于观察头身、肩头比例、轮廓和动作节奏，没有把其贴图、骨骼、模型或动画导入本次新增资源。

后续敌人统一采用女性形象；已完成的铜羽执刃者保留现有设计。女性角色通过脸部、发型与衣装剪影体现差异，并保持紧凑的战斗小人比例。

| 遭遇 | 原创角色 | 视觉与动作 |
| --- | --- | --- |
| 普通 | 暮路拾荒者 | 女性斥候、短侧辫、橄榄色兜帽、象牙颈巾、皮革背心与短直刀；轻快的前冲斩击 |
| 精英 | 铜羽执刃者 | 暗青分层礼装、象牙衬里、铜叶肩饰、交叉皮带与尖锐长剑；蓄势前冲刺击 |
| 领袖 | 蚀月档案官 | 女性术师、紫色卷发与侧辫、鸮月瓷头饰、暗紫短披风、分层法衣、卷筒与环形短杖；克制的施法动作 |

设计方向为约 3 头身、约 1.4–1.6 个头宽的肩部，使用清晰墨线和分块阴影。具体成图以资源预览为准。普通/精英/领袖可见高度约为 3.0/3.2/3.45 世界单位，与 forth 原主角的可见高度相近；级别差异主要来自装备与剪影。

资源在 `Assets/Art/Roguelike/Enemies/<角色>/Idle.png`、`Attack.png`。预制体在 `Resources/Enemies`，三个节点预制体已直接绑定。每个角色有两张原创姿态；待机呼吸、攻击位移、受击反馈和退场缩放/淡出由 `RoguelikeEnemyPresentation` 使用 Unity 原生 legacy AnimationClip 驱动。这一版是双姿态精灵动画，不是 Spine 骨骼动画，也不是完整逐帧动画。

移动的是 `Visual` 子物体，敌人的逻辑坐标和碰撞体保持稳定。死亡时立即从敌人列表注销并关闭碰撞体，之后播放 0.45 秒退场；退场期间无法再次行动、加盾、恢复或触发重复击杀。

修改两张姿态后，可以运行 `python tools/generate-enemy-prefabs.py` 重新计算像素密度并生成预制体绑定。生成器不编辑图像，保持资源 GUID 稳定。新增骨骼动画可在未来替换表现组件，继续复用 `Enemy` 的战斗逻辑。

云端 Unity EditMode 测试检查遭遇类型、每回合摸牌数、敌人预制体、双姿态绑定及死亡对象不被重新注册。最终运行时观感还需要通过 Unity 构建和浏览器试玩确认。

原生动画曲线的运行时创建遵循 [Unity 2022.3 AnimationClip.SetCurve](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AnimationClip.SetCurve.html) 的 legacy clip 接口。
