# 卡牌肉鸽事件与内容设计文档

本文档描述当前项目中卡牌 Roguelike 部分的玩法内容、节点内容、默认事件池与扩展方式。对应主要代码位于 `Assets/Scripts/CardSystem/`、`Assets/Scripts/NodeSystem/`、`Assets/Scripts/Combat/`。

## 1. 设计目标

- **地图推进**：玩家从营地出发，在随机节点地图中选择路径，逐层推进到 Boss。
- **卡牌成长**：通过营地、宝藏、商店、事件获得或移除卡牌，形成局内构筑。
- **回合战斗**：进入战斗后使用手牌消耗法力，击败敌人后回到地图。
- **低配置可运行**：节点预制体未绑定时，系统会自动生成运行时 UI 与基础内容，方便在 Unity 内快速测试。

## 2. 节点内容

| 节点 | 代码入口 | 内容 |
| --- | --- | --- |
| 营地 `Camp` | `CampManager` | 回满生命/法力，并获得指定数量的低费卡牌。 |
| 普通战斗 `Battle` | `CombatController` | 生成普通敌人，开始抽牌、出牌、敌人攻击的回合循环。 |
| 精英战斗 `EliteBattle` | `CombatController` | 生成更高血量和攻击的敌人，奖励路径风险更高。 |
| Boss `Boss` | `CombatController` 或已有 Boss 预制体 | 胜利后进入 `final` 场景；如果未配置 Boss 预制体，会生成一个精英级敌人兜底。 |
| 宝藏 `Treasure` | `RewardChoiceUI` | 从隐藏牌池给出 3 张候选卡，选择 1 张加入背包，可跳过。 |
| 商店 `Shop` | `ShopManager` | 以生命值为货币购买卡牌，或随机移除背包卡并回复生命。 |
| 事件 `Event` | `EventManager` + `EventLibrary` | 随机展示事件文本和选项，结算生命、最大生命、护盾、卡牌、删牌、赌博结果等。 |

## 3. 战斗循环

1. `DeckManager.StartCombat()` 将背包复制为抽牌堆，洗牌并抽初始 5 张。
2. `CardEffectManager.OnPlayerTurnStart()` 结算玩家与敌人的回合开始效果。
3. 玩家点击手牌，`CardCaster` 调用 `CardEffectManager.PlayCard()`。
4. 出牌成功后扣法力、执行效果、进入弃牌堆或消耗堆。
5. 点击“结束回合”后，敌人攻击，敌人回合结束效果结算。
6. 手牌弃置，抽取下一回合手牌；敌人全灭后显示胜利按钮并返回地图。

## 4. 卡牌效果绑定

`CardEffectCatalog` 负责运行时把 `CardData.cardName` 或 `CardData.effectId` 映射到具体 `CardEffect`。即使旧的 `CardData.asset` 没有手动绑定 `effect` 字段，也能在运行时正常生效。

已覆盖：

- 光：圣光庇护、神圣惩击/神圣惩戒、光明祈愿、魔法闪耀、虔心吟诵、照耀的荣光、火山回响。
- 火：二重吟唱、火焰护盾、点燃、生命火种、烈焰打击、火山。
- 草：生命滋养、荆棘缠绕、自然守护、寄生种子、生命之树、无声润物、棘藤棒。
- 水：冰霜箭、寒冰护体、激流冲刷、蚀骨丰泽、冰封领域、霜涛覆岭。
- 暗影：暗影侵蚀、暗夜突袭、影月庇护、未完成之咒、吞噬生命、绝望深渊。
- 无属性：无中生有、粮草先行、安营扎寨、现行等待、精打细算。

## 5. 默认事件池

当 `EventManager.eventPool` 没有手动配置资源时，会优先加载 `Resources/Events`，若仍为空则使用 `EventLibrary.CreateDefaultEvents()` 生成以下运行时事件。

| 事件 | 主题 | 主要选项与结果 |
| --- | --- | --- |
| 古老祭坛 | 献祭/祈祷 | 扣生命换最大生命；祈祷回复生命；离开无事发生。 |
| 受伤的旅人 | 道德选择 | 分享药水扣生命换 3 张卡；搜刮获得 2 张卡但降低最大生命；离开。 |
| 魔法泉水 | 回复/灵感 | 回复并抽卡；大量回复；抽取额外卡牌。 |
| 赌徒的挑战 | 风险收益 | 55% 成功获得 4 张卡，失败扣 25 生命；75% 成功获得 2 张卡，失败扣 10 生命。 |
| 被遗弃的宝箱 | 宝箱陷阱 | 直接拿 3 张卡；安全拿 1 张卡并加护盾；扣生命拿 4 张卡。 |
| 被遗忘的图书馆 | 知识/精简 | 扣生命换 3 张卡和最大生命；回复生命；随机删 3 张牌。 |
| 黑暗契约 | 暗影交易 | 降最大生命拿 4 张卡；删 3 张牌换最大生命和回复；拒绝。 |
| 流浪商人 | 小型交易 | 扣生命换 3 张卡；删 2 张牌并回复；小回复和护盾。 |
| 元素神龛 | 元素定向 | 火印扣生命拿火牌；水印拿水牌；光印回复并拿光牌。 |
| 镜中迷宫 | 复制/迷失 | 获得卡牌和护盾；扣生命拿更多卡；删牌精简。 |
| 无声花园 | 自然休整 | 大量回复；拿草牌；删 1 张牌并提升最大生命。 |
| 暴风断桥 | 路线风险 | 扣生命拿 3 张卡；等待获得护盾和回复；扣少量生命拿暗影牌。 |

## 6. 奖励与数值原则

- **生命作为货币**：事件和商店大量使用当前生命或最大生命交换卡牌，强化路线选择感。
- **删牌稀缺**：删牌主要来自图书馆、黑暗契约、流浪商人、镜中迷宫、无声花园和商店服务。
- **元素定向**：元素神龛、无声花园、暴风断桥提供元素筛选奖励，帮助玩家形成流派。
- **兜底体验**：没有任何事件资产时仍可游玩；后续可用 ScriptableObject 替换运行时事件池。

## 7. 扩展新事件

### 使用代码扩展

1. 在 `EventLibrary` 中新增 `CreateXXX()` 方法。
2. 用 `Choice("按钮文字", "结果描述")` 创建选项。
3. 设置选项字段：`healthChange`、`maxHealthChange`、`shieldGain`、`cardsToDraw`、`cardsToRemove`、`isGamble` 等。
4. 将新方法加入 `CreateDefaultEvents()` 返回列表。

### 使用资源扩展

1. 在 Unity 中创建 `EventData` 资源，路径推荐为 `Assets/Resources/Events/`。
2. 填写 `eventName`、`description` 和 `choices`。
3. 在事件预制体或场景中的 `EventManager.eventPool` 手动拖入资源，或留空让它自动加载 `Resources/Events`。
